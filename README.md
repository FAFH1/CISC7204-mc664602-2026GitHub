## Pair project proposal

**Title:** Uneven Recovery: Comparing Tourist Arrivals and Tourism Receipts After COVID-19

**Research question:** Between 2019 and the latest year with comparable country-level coverage, how does the recovery of international tourist arrivals compare with the recovery of international tourism receipts across World Bank regions, and which regions show the largest gap between the two recovery rates?

The full revised proposal is available in:

## Running the notebooks

1. Install Python 3 and Jupyter Notebook or JupyterLab.
2. Open the relevant `.ipynb` notebook from its module folder.
3. Install the libraries imported by that notebook, such as `pandas`, `numpy`, `matplotlib`, `seaborn`, `folium`, `plotly`, `dash`, `wordcloud`, and `squarify`.
4. Run the notebook cells from top to bottom.
5. For Dash projects, open a terminal in the relevant project folder and run the Python application file described in that lab.

Data files supplied with the labs are stored beside the relevant notebooks when available. Some geospatial or Plotly notebooks may require an internet connection to load online resources.
